# Lumin Digital

> Cloud-native digital banking platform for credit unions and community banks. Founded 2016 by Jeff
> Chambers; headquartered in San Ramon, California. Single-tenant microservices architecture layered
> on top of an institution's existing core banking processor. Serves ~90 financial institutions and
> nearly 8 million consumer accounts.

Generated by API Evangelist on 2026-08-25 from the company's public website and probes of its hosts.
Lumin Digital does not publish an llms.txt of its own (https://lumindigital.com/llms.txt returns 404).

## Important for agents

Lumin Digital HAS an API and an SDK, but publishes NO machine-readable contract publicly. There is no
OpenAPI, AsyncAPI, GraphQL SDL, Postman collection, MCP server or A2A agent card at any reachable
host. The API reference, SDK downloads and developer portal are distributed through the authenticated
client portal at https://clients.lumindigital.com/, which redirects every unauthenticated request to
/login. An agent cannot call this API without a financial-institution or ecosystem-partner
relationship. Do not attempt to infer endpoints — the platform is deployed single-tenant per
institution and has no single public base URL.

Two unrelated companies are easily confused with this one and must NOT be attributed to it:
Lumin PDF / Lumin Sign (luminpdf.com, developers.luminpdf.com) and Lumen Technologies (lumen.com).
